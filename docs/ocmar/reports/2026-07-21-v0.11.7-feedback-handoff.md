## 4. Wire 行为摘要（给对接）

### 4.1 `GET /slimapi/sessions`（200 only）

| 头 | 语义 |
|---|---|
| `X-Complete` | `"true"` iff `len(sessions) < limit` |
| `X-Discovery-Directories` | `len(directory_allowlist)` |
| `X-Discovery-Ready` | last-known-good 是否存在（true 后失败不复位） |

- 错误路径（502/503）**不**发三头。  
- `start` = epoch-ms 水位（`time_updated >= start`），**非 offset**；无前向 cursor。  
- `roots` 默认 **false**。

### 4.2 SSE

| 帧 | 何时 | 客户端动作 |
|---|---|---|
| `server.reconfigured` | discovery 集合变 **或** ready false→true | cold-start |
| `resync` | 上游重连 / 背压 / Last-Event-ID | cold-start（**未改**） |
| `server.connected` | 订阅欢迎 | **应** cold-start；与同连接 resync 合并 |

- `heartbeat` ≠ 上游健康；outage 用 `/slimapi/ready` 或自然失败。

### 4.3 Health / Ready

```json
"schema": { "degraded": bool, "version": 1, "clientMin": 1, "clientMax": 1 }
```

旧 `server.api_version` / `accepted_client_versions` 保留。

### 4.4 partId

- 真实 part：thin id = full id（schema-valid）。  
- `thin_placeholder_*`：message-level 替换，不参与 part-level 对齐。
