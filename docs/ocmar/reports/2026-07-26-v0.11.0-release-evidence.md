## 3. 阶段 A 完成项与剩余风险

### 完成项
- 第1类 sidecar 修复全部落地，rev-gpt 评审 9.5/10 PASS（有条件通过→6 项收尾已处理，见 `docs/ocmar/reviews/2026-07-26-rev-gpt-class1-slim-repair.md`）。
- 加性响应头 `X-Since-Complete`：旧客户端忽略零回归；ocdroid 阶段 A 可读（true/false/缺失三态，缺失=兼容旧 sidecar）。
- `/full` 错误路径统一结构化 503 `upstream_unavailable`（不再逃逸 FastAPI 默认 500）。
- SSE immediate flush 仅排空目标 sid，不再全局 flush 把未到期 digest 提前吐出。
- `archived` 接受真实 int（含 0），拒绝 bool 子类。
- full strip 去多余 deepcopy（in-place），降低消息路径内存。

### 剩余风险（与 rev-gpt 评审一致）
1. `X-Since-Complete` 需客户端与 `X-Next-Cursor` 联读；旧客户端忽略新头不会回归，但无法利用截断提示。
2. `/since` 地板正确性依赖当前上游（opencode v1.18.4）message-level `created` 与排序不变量；若未来上游引入可变 `updated` 或改排序，需重新设计 watermark，而非沿用当前地板逻辑。
3. body 读取异常映射依赖当前 httpx 传输栈将连接错误表现为 `httpx.RequestError`（当前部署路径符合）。
4. 第2类仍未解决（见 §5），不在本轮范围。
