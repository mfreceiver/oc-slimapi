# F-253：路径参数含解码控制字符（%0A/%0D/%09）→ httpx.InvalidURL 未捕获 → 裸 500（全 f-string 上游转发族）
- 严重度：P3
- 类别：defect（输入鲁棒性；跨 E-I/E-II/E-III 同形——非入口分层项）
- 位置：所有「f-string 插值 path 参数 → build_request」且 build 在 try 之外的转发点：src/oc_slimapi/routes/_catalog_common.py:79-91（`stream_upstream`——read_groups/messages(via :319-334)/sessions 等共用）；src/oc_slimapi/routes/write_groups.py:171-192（`_write_passthrough`）；src/oc_slimapi/routes/messages.py:496-505（`_dedicated_full_get`）
- 置信度：high（httpx 0.28.1 库级实测 + 代码结构推导；**uvicorn %0A→scope["path"] 解码为标准实现事实，未实机起服务复现——推导级**）
- 快照：0b836e7
- 状态：confirmed
## 证据
- httpx 0.28.1 实测（.venv 只读探针）：`build_request("GET", "/session/a\nb")` → `httpx.InvalidURL: Invalid non-printable ASCII character in URL, '\n' at position 10`（`\t`/`\r` 同族）。
- httpx 异常层级：`InvalidURL` 继承 Exception，**不是** `httpx.RequestError`——所有转发点的 `except httpx.RequestError` 均接不住。
- 转发点结构：`build_request`（_catalog_common.py:79-83）在 `try: send`（:91-94）之外；write_groups.py:171-176 build 在 :188-192 try 之外；messages.py:496-499 build 在 :500-505 try 之外。InvalidURL 沿调用链逃逸 → Starlette ServerErrorMiddleware 裸 500（`Internal Server Error` 纯文本，非编码错误体）。
- 入口前提：uvicorn 将 `GET /slimapi/session/a%0Ab?v=3` 的 raw path 百分号解码进 `scope["path"]`（uvicorn h11_impl 标准行为），Starlette `{sid}` 转换器 `[^/]+` 放行 `\n`。
- 影响路由族（插值参数直达 build）：`/slimapi/session/{sid}`、`/slimapi/api/session/{sid}/context`、`/slimapi/messages/{sid}`、`…/full/{mid}`、`…/expand/{category}/{mid}[/{partID}]`（mid/partID）、todo/children/diff、write 族（session_id/permission_id/request_id）。
## 分析（机制、影响面、触发条件、可达性）
- 机制：path 参数做「上游 URL 路径段」用时未经字符域校验（FastAPI `str` path param 无字符限制；`validate_directory` 只管 directory 值）。
- 影响面：单请求 500（无状态破坏、无资源占用——与 F-013 超长 LEI seq 同级同类）；附带观测盲区：该 500 由 ServerErrorMiddleware 渲染，其响应字节绕过 traffic 记账（F-023），且 access 行只有 status=500 无错误分类。
- 触发条件：`%0A`/`%0D`/`%09`（及 httpx 判非打印的其他控制字节）出现在任意插值 path 段。
- 可达性：三入口均可构造（明文/E-II 最易）；恒可达、零成本。
## 契约/文档对照
- v3-contract §9/§11 错误体族无「裸 500」归宿（未分类异常）；§8.3 优先链不含此形态——同 F-013 的契约外 500 类。
