## 分析
- 时序：熔断打开 → 文件被替换/删除 → 30s 后探针在旧 fd 上成功 → available → **恢复后至下一 tick（≤30s）的所有真实投影查询读旧库**；删除（非替换）场景旧 fd 继续可读——若无查询错误触发禁用，陈旧窗口理论上可超过一个 tick（marker 比对在下一 tick 必然不等 → swap，故实际上界 ≈30s）。
- 契约面：§4.5 不承诺并发/新鲜度语义——非契约违反；swap 机制（§4.1 设计目的）在熔断窗口失效属实现缺口。
- 修复注意：探针即使改为触表（如 SELECT 1 FROM session LIMIT 1）也不能替代 inode 校验——正确修法是 ① 的 inode 检查对 circuit_open 态也执行（在 probe 之前）。
