## 分析（机制、影响面、触发条件、可达性）
- str 直通分支生产不可达（上游恒对象信封）；属无害防御码。dict 分支只读 `type` 键，信封其余字段（retry 的 attempt/message/next）被丢弃——retry 会话 digest.status="retry"，细节不上 wire（契约允许）。
- 附带收益确认：digest.status 值域可据上游 schema 冻结为 idle|retry|busy 三值（v3 §7.6 目前表述为「busy/idle 等上游状态值原样」，未枚举关闭）。
- 附带核查：信封无效形状（缺 type / type 非字符串）→ None → 该次状态更新被忽略——与 v3 §7.6 / v4 §7.5「信封无效时该次状态更新被忽略（digest 其余字段不受影响）」冻结文本一致，**非缺陷**。
