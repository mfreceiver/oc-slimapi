## 证据
- 上游真值（opencode-src/current → v1.18.18）：`packages/core/src/database/schema.gen.ts:183` `\`id\` text PRIMARY KEY`；`:209` `\`time_updated\` integer NOT NULL`（drizzle `Timestamps.time_updated` 带 `$onUpdate(() => Date.now())`，schema.sql.ts:7-9——恒写整数）。→ NULL / REAL / TEXT 形态的 time_updated 在当前对齐版本**不可达**。
- sidecar 行为（假想形态下的推演，代码路径复核）：
  - NULL t：`ORDER BY time_updated DESC` NULL 排尾 + 谓词 `(t < ? OR (t = ? AND id < ?))`（projection.py:226）对 NULL 恒假 → NULL-t 行只可能出现在**整表一页装下**的首窗；多页翻页永不可达（静默丢行）。
  - REAL/TEXT t：行可被 SQL 返回与排序（数值比较），但 `_window_anchor` 要求 `isinstance(t, int) and not isinstance(t, bool)`（projection.py:326-328）→ 非 int-t 行不可为锚；窗口尾部全为非 int-t 行时 anchor=None + complete:false → sessions.py:469 `not complete and anchor is not None` 不成立 → **无 nextCursor 的死端页**（「还有更多但拿不到游标」，客户端重启翻页才可续）。
- schema 门不设防：lifecycle.py:97-107 仅集合判定列名 ⊆ 实有列，不校验类型/NOT NULL/PK——上游改型（integer → real/text，或去 NOT NULL）时门通过、上述路径复活。
