# F-248：`//` 前缀路径经 file://authority URI 语义静默丢首段——UNC 风格手配路径错库
- 严重度：P3
- 类别：defect
- 位置：src/oc_slimapi/dbaux/lifecycle.py:506（`quote(path, safe='/')` 保留双斜杠）+ path_resolution.py:100,112,117（normpath 不归并双前导斜杠）
- 置信度：medium-high（POSIX normpath 语义 + SQLite URI authority 规则实证推导，快照 0b836e7）
- 快照：0b836e7
- 状态：confirmed
## 证据
- 实证（python3 -c）：`posixpath.normpath('//srv/share/x.db')` = `'//srv/share/x.db'`（POSIX 规范保留恰两个前导斜杠）；`quote('//srv/share/x.db', safe='/')` 原样保留 → URI = `file://srv/share/x.db?mode=ro`。
- SQLite URI 规则：`file://authority/path` 形态中 authority 段在 unix 上被跳过——实开 `/share/x.db`（首段 `srv` 静默丢失）。
- 可达路径：`OC_SLIMAPI_OPENCODE_DB=//srv/share/opencode.db`（运维手配 UNC 风格/mount 点笔误）→ ResolvedPath → 错误文件：目标不存在 → open_failed（可诊断）；cwd 下恰有被截断路径的库 → 静默错库（schema 门可能通过）。
- 注入面结论不受影响：`?`/`#`/空格/`%`/`\` 的转义已封闭（D07 §1.3 表）——本条是 `//` 前缀的**语义**缺口而非注入。
## 分析
- 触发面：仅显式 env 手配 `//` 前缀（XDG/候选发现路径不产生双前导斜杠）；低频。
