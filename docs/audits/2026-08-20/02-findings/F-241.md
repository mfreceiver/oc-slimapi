# F-241：explicit-env 相对路径未拒（连带 XDG_DATA_HOME 相对值未校验）——file: 相对 URI 按进程 cwd 打开
- 严重度：P3
- 类别：defect

## 证据
- explicit 分支（path_resolution.py:95-100）：非 `":memory:"` 值直接 `_expanduser + normpath` → `ResolvedPath(source="explicit-env")`——**无 `os.path.isabs` 校验**（对比 upstream-env 相对路径 :116-119 有「挂数据目录」的显式语义）。
- 实证（python3 -c，纯函数）：`quote('rel/x.db', safe='/')` → `file:rel/x.db?mode=ro`——SQLite URI 接受相对路径，按**进程 cwd** 解析。
- systemd user 服务（docs/operations.md 部署形态）cwd ≠ 运维者 shell cwd——同一 env 值在不同启动方式下解析到不同文件（或 not-there→open_failed）。
- 连带：`_data_dir`（:77-79）对 `XDG_DATA_HOME` 非空即用作 base（XDG 规范要求绝对路径）——相对值 → data_dir 相对 → 候选 glob（:124）按 cwd 相对执行。
- 测试面：tests/test_db_path_resolution.py 11 case 全用绝对/`~` 形态，相对 explicit 值零覆盖。
## 分析
- 影响：错库（读到 cwd 下恰有的同名库 → schema 门可能通过 → **静默投影错误数据**）或 open_failed 禁用（可诊断）。前者是真实风险面。
- 触发面：`OC_SLIMAPI_OPENCODE_DB` 配置笔误（漏前导 `/`）——配置面，非客户端面。
- 对比语义：upstream-env 相对路径被显式定义为「挂数据目录」（复刻上游 database.ts:44-46）；explicit 分支无此定义也无拒绝——三级解析中唯一未定义相对语义的分支。
