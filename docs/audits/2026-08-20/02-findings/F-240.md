- **(a) stat 失败分支**：open 成功后文件即被删除（`stat_inode_marker` OSError → None，path_resolution.py:143-144）→ `self._inode=None`；:604 守卫要求 `_inode is not None` → **该连接存续期内 swap 检测永久静默失效**——陈旧读无界（仅查询错误禁用或重启可破）。
- **(b) open→stat 间隙换库**：t1 `_open_conn`（:531）取得旧文件 fd；t2 `os.replace` 新文件；t3 `stat_inode_marker`（:546）记录**新文件** marker → `_inode`=新值 → 此后每 tick `marker == _inode` → **永不触发 swap**，连接终生读旧（已 unlinked）文件。间隙宽度 = schema 门查询时长（毫秒级）；reprobe/swap 与上游恢复（备份还原等替换操作）并发时可命中。
- **对 e1-08 卡片疑问 6a 的推翻**：该卡片判此场景「下个 tick 再 swap 一次（自愈，良性）」——方向性错误：记录新 marker 恰好使后续比对恒等，**不会**再 swap。
- 测试面：tests/test_dbaux_lifecycle.py inode 用例（:406-446）全走「替换成功且 stat 成功」路径；(a)/(b) 零覆盖。
