- 严重度：P3（A9 初判；risk——触发需上游半开（进程僵死/网络路径黑洞），单机 loopback 部署概率低）
- 类别：risk

## 证据

- 恢复路径仅 EOF/异常（:1056-1090 退避重连 + `_notify_upstream_loss`）。
## 分析（机制、影响面、触发条件、可达性）
上游 TCP 半开（对端进程僵死但连接未 RST、或中间路径黑洞）时，`aiter_lines` 永久挂起：控制面/token 全部订阅者收不到任何帧也收不到 resync——**静默全停**，直至 OS 层 TCP keepalive（默认 ~2h+）或物理断连。loopback 部署下进程僵死通常伴随连接关闭（EOF/EBADF），半开需特定故障形态（SIGSTOP、cgroup freezer、netns 异常）。与 F-014（非 dict JSON 拆连接）同为上游事件流可用性风险面。
