## 分析（机制、影响面、触发条件、可达性）
- 机制：swap 判据把「正常写活动的 checkpoint 侧影」与「文件替换」混同。写频繁上游（长会话高频 prompt）→ WAL 每 1000 页 checkpoint → 主库 mtime 每 checkpoint 变 → 每 30s tick 触发 swap。
- 影响：(1) `breaker.reset()` 反复清零 → **P99 熔断护栏在写频繁期形同虚设**（warmup 10 次豁免重起算，慢查询永不累积成 trip 证据）；(2) generation/swaps 计数膨胀（metrics 观测失真——swap 事件不再意味换库）；(3) 连接反复 close/open（fd churn + schema 门重跑，开销小）；(4) info log 噪声（:605-607）。
- 可达性：生产常态（上游活跃 + 30s tick 对齐）。
