## 证据
- sessions.py:389-393：`if limit > _V4_LIMIT_MAX: raise CodedHTTPException(422, code="param_version_mismatch", hint=f"v4 limit domain is 1..{_V4_LIMIT_MAX}")`——501..1000 值通过 FastAPI `le=1000` 校验后由此分支接住（coded body `{"code":"param_version_mismatch","hint":...}`）；
- sessions.py:683：`limit: int = Query(100, ge=1, le=1000)`——`limit=1001+`、`limit=0`、非整数在 FastAPI 校验层被拒，body 为框架形状 `{"detail":[...]}`（无 `code` 字段）；
- 测试锁定：tests/test_sessions_v4_matrix.py:471 `test_v4_limit_501_422_and_500_ok`（501 → 422，500 → 200；**未断言 body 形状**）；:575 `test_v3_limit_1000_domain`（v3 limit=1001 → 422 注释「FastAPI declarative domain」——双形状被测试如实锁定）；
- 契约原文（§4.1 参数矩阵）：`&limit=1..500  # v4 域（v3 保持 1000）`——仅声明域，**未声明域外值的错误归宿**；§4.3 错误族表 422 行触发枚举 = 「v4 收 roots/start；v3 收 archived/parent/cursor」，**不含 limit 超域、archived 非法值、parent 空串**（三者实现均复用 `param_version_mismatch`，sessions.py:389-401）。
## 分析（机制、影响面、触发条件、可达性）
- A4 裁决（对 §4.1 原文逐条）：
  1. **契约侧缺口**：§4.1 冻结 `limit` v4 域 1..500，但域外值（501..∞、≤0、非 int）的错误归宿（状态码/码字/body 形状）在 §4.1/§4.3 均未载——错误路径不穷尽（四问 (ii) 不通过）。同理 `archived` 非三态值、`parent` 空串的归宿未载（实现选 422 param_version_mismatch + hint）。
  2. **实现双形状**：v4 limit=501..1000 → coded 422；limit>1000 / ≤0 / 非 int → FastAPI 框架 422（`{"detail":…}`）。两段同为「limit 域外」语义却 body 形状不同，且分界线是 **1000（v3 声明域）而非 500（v4 冻结域）**。
  3. **码字面量无契约名**：`param_version_mismatch` 字面量在 v3/v4 契约全文从未出现（rg 负向证据：`rg -n 'param_version_mismatch' docs/specs/` → 空；§4.3/§8.1 只写中文描述「参数版本不匹配」）——客户端无法从契约机械得知 code 串（唯一载体 CHANGELOG 一次提及）。
  4. v3 侧 `archived/parent/cursor` presence 拒绝（sessions.py:700-705）与 §4.1 矩阵一致（无问题）。
- 影响面：仅错误路径表示细节；正确参数的客户端零感知。按 `code` 解析错误的客户端在 limit>1000 时会拿到无 `code` 的框架 422。
- 触发条件：v4 客户端发送 limit>500（或 archived 非法/parent 空）。
## 契约/文档对照（规范轨引文）
- v4-contract §4.1（`limit=1..500` 域冻结）、§4.3（422 触发枚举）、§8.1（「参数版本不匹配（v3 收 v4 参数 / v4 收 v3 参数）| 422」）——枚举窄于实现触发集；
- v3-contract §8.1「422 形态不变」（沿 v2）——FastAPI detail 形状是否即 v2 422 形态：v2 契约对 typed query 参数越界的 422 未逐字冻结（历史行为即框架形状），故 >1000 形状可论证为「未提及语义沿 v2」；但 v4 `?v=4` 是新面，无 v2 基线可沿——**v4 面上的域外归宿是纯缺口**。
