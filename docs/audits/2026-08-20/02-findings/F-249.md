## 证据
- path_resolution.py:68-69：`if p.startswith("~") and home is not None: return p.replace("~", home, 1)`——注入 home 时纯字符串替换：`"~bob/x.db"` + `home="/home/tester"` → `"/home/testerbob/x.db"`（**缺路径分隔符**，实证 python3 -c）。
