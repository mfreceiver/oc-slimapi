## 分析（机制、影响面、触发条件、可达性）
帧内容受三维界（2048/域、64 MiB 总额、900s TTL）严格约束，但**域外壳字典本身**随「本 epoch 内出现过 token 帧的 sid 数」单调增长（首个 token 帧即 lazy 建域，:369-372）。每外壳 = `_DomainState`（slots：deque + 5 标量，:214-225）≈ 数百字节；10⁴ sid ≈ 数 MB。键空间 = 实际 opencode 会话数（单用户自然小）；删除会破坏 seq 不回归不变式（REPLAY-018）——**有意设计**，且代码注释已披露权衡。重启（新 epoch）为 GC。
## 契约/文档对照（规范轨引文）
- v4-contract §7（id 序列无空洞/同 epoch seq 单调）——shell 保留是该契约的实现代价。
